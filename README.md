# نیکو سلامت — React + FastAPI / PHP

وب‌سایت فارسی و راست‌به‌چپ نیکو سلامت برای معرفی محصولات سلامت دام و اسب.

## ساختار پروژه

- `frontend/src/app`: اتصال هوک‌ها، چیدمان و مسیرهای برنامه.
- `frontend/src/features`: بخش‌های مستقل خانه، محصولات، مقالات، محتوا، درباره ما، تماس و مدیریت.
- `frontend/src/components`: اجزای مشترک رابط کاربری و چیدمان.
- `frontend/src/hooks`: منطق مشترک ناوبری، داده‌ها، سبد و پیام‌ها.
- `frontend/src/services/api`: کلاینت HTTP و سرویس‌های API تفکیک‌شده.
- `frontend/src/styles`: استایل‌های بخش‌ها و فایل‌های ریسپانسیو با ترتیب بارگذاری مشخص.
- `backend/app`: API توسعه با FastAPI، مدل‌ها، دیتابیس و محتوای اولیه.
- `backend/tests`: تست‌های API.
- `.deploy/cpanel-php`: API محیط cPanel؛ انتشار آن از طریق GitHub Actions و کران انجام می‌شود.

جزئیات مسئولیت پوشه‌ها و دستورات فرانت در [راهنمای فرانت‌اند](frontend/README.md) آمده است.

## اجرای سریع

از پوشه اصلی پروژه اجرا کنید:

```powershell
npm run dev
```

برای نمایش سایت روی دستگاه دیگری در همان شبکه Wi-Fi، ابتدا نسخه نهایی را بسازید و سپس سرور اشتراکی را اجرا کنید:

```powershell
npm run build
npm run serve
```

سپس روی دستگاه دوم آدرس `http://IP-LAPTOP:8011` و برای پنل مدیریت
مسیر مدیریت تعریف‌شده در `frontend/src/app/adminRoute.js` را روی همان آدرس باز کنید. در این سیستم، IP شبکه فعلی لپ‌تاپ را
می‌توانید با `ipconfig` پیدا کنید.

این دستور فرانت‌اند و بک‌اند را هم‌زمان اجرا می‌کند. برای توقف هر دو، `Ctrl+C` بزنید.

## اجرا

### بک‌اند

```powershell
cd backend
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8011
```

مستندات API در `http://127.0.0.1:8011/docs` در دسترس است.

### فرانت‌اند

در ترمینال دوم:

```powershell
cd frontend
npm install
npm run dev
```

سایت معمولاً در `http://127.0.0.1:5173` اجرا می‌شود؛ اگر این پورت اشغال باشد Vite پورت بعدی مانند `5174` را انتخاب می‌کند.

در حالت توسعه، آدرس پیش‌فرض API برابر `http://127.0.0.1:8011` است. برای تغییر آن متغیر `VITE_API_URL` را تنظیم کنید.

## داشبورد مدیریت

مسیر داشبورد در `frontend/src/app/adminRoute.js` تعریف شده است؛ آن را به آدرس محلی اضافه کنید. مسیر قدیمی `/admin` غیرفعال است. این مسیر تصادفی جایگزین احراز هویت نیست و از کد فرانت‌اند قابل کشف است. اطلاعات ورود پیش‌فرض محیط توسعه:

```text
نام کاربری: admin
رمز: 1234
```

برای هر محیط واقعی، پیش از اجرا حتماً اطلاعات ورود را با متغیرهای محیطی تغییر دهید:

```powershell
$env:SOVARA_ADMIN_USERNAME="owner"
$env:SOVARA_ADMIN_PASSWORD="a-long-unique-password"
npm run dev
```

رمز به‌صورت PBKDF2 در SQLite ذخیره می‌شود و عملیات افزودن یا حذف محصول فقط با نشست معتبر ادمین امکان‌پذیر است. تصویر محصول می‌تواند JPG، PNG یا WebP و حداکثر ۳ مگابایت باشد.
