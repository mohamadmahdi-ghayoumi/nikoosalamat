# سُوارا — React + Python

پروژه فول‌استک فروشگاه ایرانی محصولات مراقبت از اسب.

## اجرای سریع

از پوشه اصلی پروژه اجرا کنید:

```powershell
npm run dev
```

برای نمایش سایت روی دستگاه دیگری در همان شبکه Wi-Fi، ابتدا نسخه نهایی را بسازید و سپس سرور اشتراکی را اجرا کنید:

```powershell
npm run build
npm run serve
```

سپس روی دستگاه دوم آدرس `http://IP-LAPTOP:8011` و برای پنل مدیریت
`http://IP-LAPTOP:8011/admin` را باز کنید. در این سیستم، IP شبکه فعلی لپ‌تاپ را
می‌توانید با `ipconfig` پیدا کنید.

این دستور فرانت‌اند و بک‌اند را هم‌زمان اجرا می‌کند. برای توقف هر دو، `Ctrl+C` بزنید.

## اجرا

### بک‌اند

```powershell
cd backend
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8011
```

مستندات API در `http://127.0.0.1:8011/docs` در دسترس است.

### فرانت‌اند

در ترمینال دوم:

```powershell
cd frontend
npm install
npm run dev
```

سایت معمولاً در `http://127.0.0.1:5173` اجرا می‌شود؛ اگر این پورت اشغال باشد Vite پورت بعدی مانند `5174` را انتخاب می‌کند.

در حالت توسعه، آدرس پیش‌فرض API برابر `http://127.0.0.1:8011` است. برای تغییر آن متغیر `VITE_API_URL` را تنظیم کنید.

## داشبورد مدیریت

داشبورد در آدرس `http://127.0.0.1:5173/admin` قرار دارد. اطلاعات ورود پیش‌فرض محیط توسعه:

```text
نام کاربری: admin
رمز: 1234
```

برای هر محیط واقعی، پیش از اجرا حتماً اطلاعات ورود را با متغیرهای محیطی تغییر دهید:

```powershell
$env:SOVARA_ADMIN_USERNAME="owner"
$env:SOVARA_ADMIN_PASSWORD="a-long-unique-password"
npm run dev
```

رمز به‌صورت PBKDF2 در SQLite ذخیره می‌شود و عملیات افزودن یا حذف محصول فقط با نشست معتبر ادمین امکان‌پذیر است. تصویر محصول می‌تواند JPG، PNG یا WebP و حداکثر ۳ مگابایت باشد.
